Implementasi Server Sendiri (On-Premise / Private Hosting)

Cocok untuk instansi, koperasi, atau perusahaan yang ingin sistem berjalan menggunakan domain milik sendiri, terpisah sepenuhnya dari klien lain.

  • ✓ Domain & branding milik sendiri (mis. akuntansi.namainstansi.go.id) — tampil lebih profesional dan meningkatkan kredibilitas institusi
  • ✓ Tanpa biaya langganan bulanan — investasi sekali di awal, lebih hemat jangka panjang
  • ✓ Data tersimpan terpisah sepenuhnya, tidak berbagi server dengan pengguna lain
  • ✓ Kontrol penuh atas server, kebijakan akses, dan keamanan data
  • ✓ Kustomisasi fitur & tampilan sesuai kebutuhan instansi
  • ✓ Tidak bergantung pada ketersediaan/uptime pihak ketiga
  • ✓ Bantuan instalasi awal & migrasi data
  • ✓ Pelatihan penggunaan sistem gratis untuk tim Anda

FAQ

Pertanyaan Umum

Apakah bisa upgrade kapan saja?

Ya, upgrade bisa dilakukan kapan saja. Fitur baru langsung aktif setelah pembayaran dikonfirmasi.

Apa setelah trial berakhir?

Akun tetap aktif dengan akses terbatas. Data aman tersimpan. Upgrade kapan saja untuk akses penuh.

Apakah data saya aman?

Ya. Data disimpan di cloud dengan enkripsi & backup otomatis (Railway & PostgreSQL).

Apa itu fitur Unit/Cabang?

Kelola data keuangan per lokasi/cabang. Premium: 2 unit, Enterprise: 5 unit.

Apa itu Proyeksi & Rasio Keuangan?

Estimasi arus kas ke depan & indikator kesehatan keuangan otomatis. Premium & Enterprise.

Bagaimana paket Academic untuk kelas?

Dosen daftar gratis, dapat kode referral untuk mahasiswa (diskon 30%). Data bisa direset kapan saja.

Metode pembayaran apa saja?

Transfer bank, kartu kredit/debit, e-wallet (GoPay, OVO, Dana) via Xendit.

Ada biaya tersembunyi?

Tidak ada. Harga sudah all-inclusive. Trial 3 hari gratis tanpa kartu kredit.

Siap Mulai dengan SIKANCIL?
